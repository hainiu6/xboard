# 126 用户端界面维护

默认 Xboard 主题新增品牌首页、登录页及套餐购买页，保持 Laravel API 与原有鉴权机制。

## 页面源码

- 首页：`theme/Xboard/home.blade.php`
- 页面入口和站点配置：`theme/Xboard/dashboard.blade.php`
- 全站样式：`public/assets/126/theme.css`
- 首页/登录/用户中心切换：`public/assets/126/portal.js`
- 套餐选择、优惠券与直接付款：`public/assets/126/plan-catalog.js`
- 用户订单记录：`public/assets/126/orders.js`
- 公告正文：`public/assets/126/notices.js`
- 后台公告页面勾选：`public/assets/126/admin-notice.js`
- 品牌图标：`public/assets/126/logo.svg`

套餐、周期、支付方式、手续费、优惠券及账户余额使用原有 API 数据。月均价格和周期节省金额只用于展示；创建订单后使用服务器返回的应付金额，再发起支付。跳转收银台或在当前页面显示二维码，不跳转原订单页。

有待付订单时可在当前页继续付款或取消；订单创建后锁定套餐和优惠券，付款失败重试复用原订单。余额全额抵扣时直接完成付款流程。支付接口不在预览或测试中访问真实线上订单。

购买页默认选中名称以 V3 开头且支持年付的套餐，使用后台套餐 ID 和真实年付价格。切换任意套餐的购买周期后，所有卡片同步显示该周期月均价格；不支持该周期的套餐显示“暂不提供此周期”，避免误导。切换套餐或周期后重新校验优惠券，已创建订单仍锁定原套餐。

登录后的用户中心只保留原有导航栏，其中提供返回首页按钮。购买页结算栏固定在窗口底部，跟随侧栏宽度变化；页面底部预留等高空间。付款按钮的呼吸动画遵循系统“减少动态效果”设置。

## 编译主题桥接

上游只提供用户端编译产物。`scripts/build-user-theme.py` 将维护的套餐页接到原路由，并复用原 Vue、二维码组件和 API 客户端，保留鉴权、服务端校验和其他页面。

更换上游 `theme/Xboard/assets/umi.js` 后运行：

```bash
python3 scripts/build-user-theme.py
node tests/plan_catalog_test.mjs
```

脚本可重复执行；上游组件边界变化时会停止并要求检查。修改套餐页源码和样式不需要重新编译原前端。模板为资源添加版本标记，更新后可加载新资源。

不要在页面源码中填写实际价格、支付密钥或用户凭据。真实线上支付、到账回调和开通结果需在服务器更新后另行验证。

## 导航、订单与登录

购买订阅在使用文档下方；节点状态从侧栏隐藏，原有节点 API 和订阅能力保留。订单页提供状态筛选、套餐/订单号搜索及分页；只有待支付订单可取消，取消需确认。继续付款将携带订单号进入购买页，只恢复当前用户自己的待支付订单，不创建新订单。

前端登录凭证保存期限为 365 天，与后端原有一年凭证期限配合使用；更新后重新登录生效。退出登录、后台撤销会话及后端验证仍有效。

## 公告显示页面

后台“系统管理 → 公告管理 → 编辑/添加公告”可勾选仪表盘、购买订阅、我的订单、使用文档、个人中心、我的邀请、我的工单、流量明细。每个页面只直接显示按原排序最靠前的一条启用公告；不弹窗、不展示公告列表。Markdown 和常用 HTML 格式通过安全过滤后展示。

`v2_notice.display_pages` 为新增可空 JSON 字段，更新脚本自动迁移。旧公告为空时只在仪表盘显示；明确保存空数组时任何页面都不显示。页面参数经过服务端白名单校验，未启用公告不会返回。

更换后台编译产物后也需运行 `python3 scripts/build-user-theme.py`，以恢复公告表单的受控字段与校验。后台入口和新增模块都带资源版本标记。

## 蓝色公告卡片示例

将 `docs/zh-CN/notice-example.html` 完整复制到后台公告内容中。示例包含深蓝标题栏、当前影响、处理进展、使用建议与致歉说明；只修改文字即可复用样式。示例请关闭“显示”，正式启用前核实影响范围和恢复状态。

公告只允许指定 `notice-card-*` 样式类；任意 CSS、脚本、事件属性仍会被过滤。
